# IP753 0.6.7 内存优化阶段记录

2026-10-26，包名 `xyz.i4o.uni.launcher`，版本 `0.6.7+18`。

主界面、常驻底栏和临时面板改用 FlutterEngineGroup。临时面板关闭 5 秒后销毁；关闭最近任务时清空截图数据。图标缓存限制 256 项 / 4 MiB，最近任务图像限制 48 项 / 12 MiB；每个 Flutter 引擎的解码图片缓存限制 128 项 / 24 MiB，替换封面时淘汰旧图片。内存压力通知同时转发到各引擎和地图预览。

原车旧日志曾记录 `ecarx clean` 清理网易云，当时桌面 PSS 约 449 MiB；不能据此断言存在内存泄漏。优化版的三分钟后台观察共 7 次采样，网易云 PID 均为 14467，始终播放且正常跨曲，桌面 PSS 309–347 MiB，末次约 314 MiB。最终静态预览版本另观察 60 秒，5 次采样均正常播放，桌面 PSS 从约 317 MiB 回落到 298 MiB。场景并非严格相同，以上是现场采样，不是受控性能对比，也不代表长时稳定性已通过。

Android 9 模拟器四轮面板测试通过：面板打开时 3 个引擎，关闭后回到 2 个，最近任务截图清空、面板可重建，底栏没有额外重排。102 项 Flutter 测试通过，analyze 无问题，arm64 / x86_64 release 构建通过，实车签名 APK 已覆盖安装并核对 SHA。

地图预览曾因隐藏后的 SurfaceTexture 消费队列阻塞恢复。阶段版本已换成最长边 640 像素的 JPEG 预览，位图复用，任务队列有上限，隐藏或压力时释放。JPEG 只用于恢复占位，正常地图由高德实时绘制；跨应用弹窗也继续使用静态背景快照，不增加实时截图毛玻璃。

**地图尚未验收通过。** SurfaceFlinger 现场记录显示，高德同一个窗口同时保留 1920×984 与卡片尺寸的透明 UI Surface，产生重复导航信息；不是 Flutter 缩略图叠加。部分恢复曾卡住。已改为解析应用 Manifest 声明的 `androidauto://launch_do_nothing` 入口，避开 USB 导入启动中转页；重新显示时激活实际地图任务。实车截图仍发现残留层，不能标记叠加问题完成。

用户随后要求换屏也使用实时画面，下一阶段将移除静态地图占位，改用原生 VirtualDisplay 直接输出 Flutter 纹理，单独验证触控、跨屏、全屏恢复和资源释放。截图显示车辆行驶期间停止界面操作，仅保留后台观察。方向盘、仪表盘及空调本轮未重测；导航播报不降音乐音量的原车空接口限制仍见 0.6.6 记录。

```sh
python3 tools/observe_music_memory.py --serial 192.168.5.1:5555 \
  --duration 180 --interval 30 --out car-reports/music-memory
```
