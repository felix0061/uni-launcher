# UNI 0.5.0：全局底栏与车辆卡片

包名 `xyz.i4o.uni.launcher`，版本 `0.5.0+7`。2026-10-25 已通过车机热点无线 ADB 完成首轮实车验证，结果见 [0.5.0 实车报告](../app/verification/car-050-report.json)；长时与运动状态项仍在待办。

## 已实现

- 底栏全宽直角、取消外边距和底部装饰留白，高度为 96 设计像素；内部控件继续跟随主题圆角。桌面设置仍长按首页进入。
- 设置中新增全局底栏与隐藏系统原有导航栏两个独立开关。前者使用前台悬浮窗口，在桌面隐藏副本、其他应用显示；后者保存并有条件恢复原 policy。原厂 360 包排除在全局隐藏规则外。
- 全局窗口复用同一套底栏、应用列表、音乐／空调／车辆面板，所有窗口共用单例原生 Runtime。系统 HOME 返回会清除旧展开面板，避免下次进入外部应用浮出旧面板。
- 动力电池卡片显示电量、驾驶模式、能量流；车内空气卡片显示 PM2.5 与独立 AQI；行车信息保留速度、里程、续航、保养。支持添加、编辑、缩放、删除及主题／圆角。
- 驾驶模式、混动选择、能量流按本车 SDK 精确原始属性新增只读采集，拒绝未知枚举和无效 PA；外接充电仍显示待同步。专用电池续航只收诊断原值，有效域未核实前不显示数值。
- 原厂天气／日历／账号／清理入口使用精确 Provider 匹配，补齐 Widget 绑定、配置、取消回收、复用和可访问应用回退。
- JDK 与实车签名输入改为持久本地工具目录，不依赖临时目录；私钥和 APK 均不提交源码仓库。

## 实车验证结果（2026-10-25）

- 同证书覆盖安装 0.4.2 → 0.5.0 成功，数据保留；冷启动 2.75 秒，全会话无崩溃。0.4.2 的 944/136 窗口修复保持有效。
- 新增 PHEV 只读字段实车读数：驾驶模式=混动(8)、混动选择=已选(1)、能量流=静止·发动机关闭(7)；电量 92%、PM2.5/AQI=0；专用电池续航 raw=73/km，按未证实域规则保留诊断不显示。
- 全局底栏实测：经设置开启后 1920×96；隐藏系统导航栏后 policy 正确写入并排除原车 360 包，视口 944→1080，底栏贴底（y 984+96=1080）无空隙；外部应用上可见并可渲染，跨应用暂停真实网易云生效，空调面板展开/返回收起、长按首页进设置、回桌面无重复底栏；关闭后 policy 恢复 null、视口恢复 944。
- 原车 360：启动链路已按官方 Launcher3 组件启用流程实现并验证——活动被系统创建后由原车应用自行关闭（app-request，非倒挡门槛）；本车能力值返回 255，已增加“按当前组件启用状态启动”的兜底；倒挡画面待车辆移动时验证。
- 空调与座椅写入实车验证：主驾温度 22.5→23→22.5、座椅加热 1 档开/关均 confirmed 读回；我们的温度读数与原车栏显示同为 22.5（同刻一致）。
- 媒体实车验证：网易云下一首/上一首/拖动进度（跳转 79 秒）/播放暂停全部可用。
- 实车限制：policy_control 隐藏只取消占位（视口 944→1080），SystemUI 的 CarNavigationBar 仍绘制在最上层，因此实车上保留开关默认关闭、底栏停在原车栏上沿（y 848）；真隐藏需原车系统支持。设置页底栏区域存在命中测试异常（首页按钮可用、温度按钮无响应），已列入跟进。

## 白天上车验收

1. 覆盖安装同证书 IP753 包；核对启动、原车权限与深浅主题。确认 0.4.2 的地图／窗口修复未回退，切屏、设置和全屏导航不残留地图 Surface。
2. 手动开启全局底栏和隐藏系统导航栏，分别测试组合、权限拒绝、关闭恢复；检查外部应用底部是否被遮住。普通 overlay 不会自动压缩其他应用的工作区。
3. 核对原厂 360 与硬件倒车接管。手动点击原厂影像时已暂停全局底栏，但自动倒车／相机状态订阅尚未验收；不把手动入口测试视为倒车验收。
4. 同刻对照 SOC、驾驶模式、混动选择、能量流、PM2.5／AQI、胎压及单位。新增字段未采实车样本；电池续航的原始数据、format/status 与无效编码需单独确认。
5. 静止状态逐项触发空调／座椅，并检查命令发送和读回。网易云上一首／下一首／播放暂停／拖动进度／歌词仍需真实应用核对。
6. 读取原厂天气、账号、日历、清理的主 APK／Provider 合约。兼容宿主显示不等于统一卡片字段已同步；完整迁移的缺口见 [官方能力对照](OEM_PARITY_0_5.md)。
7. 开机、休眠唤醒、权限变化、长时间运行与资源占用。模拟器通过不代表 MSM8996 实车性能通过。
