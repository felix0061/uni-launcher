# IP753 0.4.2 接入与回归

版本 `0.4.2+6`，包名 `xyz.i4o.uni.launcher`。原始车机日志、个人媒体内容、地图截图及厂商 APK 留在忽略的 `car-reports/`；本报告和可复现测试由本地 Git 管理。

## 窗口与地图

底栏不跟随波动的系统 inset 重布局；按 Decor 高度与稳定系统栏保留区计算可用高度，并取与原生内容高度的较小值。实车曾在焦点切换后由 944 扩到 1080，但原车底部 136 像素仍然覆盖；修复后两种状态的 Flutter 高度均为 944，底栏保持可见。Android 9 实际嵌入地图时，各桌面页保持挂载，直接切页，不将原生 Surface 放进 Flutter AnimatedSwitcher；未嵌入地图时仍保留用户选择的翻页动画。

地图允许创建与是否显示分开；切到另一页、进入设置或弹窗只隐藏地图，保留 ActivityView 和 VirtualDisplay。恢复前重新核对真实显示对象、有效 Surface 和任务归属。临时隐藏不移除容器；真正释放按 release、remove、清理引用顺序。多张导航卡片以当前可见卡片为 owner。设置预览继承禁止嵌入策略，不创建第二张地图。

高德已有 singleTask 先迁入目标显示，不重复启动；没有任务时才通过 ActivityView 启动。避免先激活旧全屏任务、导致桌面停止而打断迁移。只移动选中导航应用自己的单任务栈。

实车回归：切到其他页再返回，地图 viewId=0、displayId=92 保持不变；进入设置后 cardVisible=false，截图确认地图没有浮到设置上，预览没有创建第二实例。返回后真实地图可见，底栏位置稳定。高德内部偶发顶部黑条仍需后续核对应用自身布局；当前虚拟屏窗口 bounds/insets 均覆盖完整容器，不硬编码裁图。

## 媒体

QQ 音乐保持原 MediaSession 元数据、歌词和控制路径。网易云车机版有回调但未声明 PlaybackState actions，增加精确包名适配，定向媒体按键控制与毫秒 seek；进度条现在实际发送 seek。完整 LRC、当前句事件分别处理，切歌清理旧内容。

当前网易云安装版本对外歌词上送默认关闭，APP 内显示歌词与对外上送不是同一开关。桌面已接收已核对的 metadata/event 格式，未收到时明确提示；不宣称此 APK 已能显示全文歌词。说明见[网易云接口](NETEASE_MEDIA.md)。

## 官方车辆接口

替换不存在的旧 ecarxcar_service，正式使用官方 Launcher3 相同的 Car.create/IConnectable/ICarFunction，辅以同源 CarPropertyManager 的 PA 状态与时间戳。协议按实际 sint32 ZigZag 解码，并逐项比较 SDK getter 的映射。

已经读到双区温度、风量、电源、AUTO、AC、循环、同步、主驾加热/通风、副驾加热、四轮胎压原始值，以及车内 PM2.5、AQI、动力电池百分比。温度变化可与原车底部区同时观察。胎压物理单位、额外速度/里程/续航的单位尚未闭环，保留原始值或未知，不猜单位和转换。

车控只由用户点击触发。逐项检查支持、权限、有效读数、SDK 映射和新鲜度；温度、风量、模式和座椅命令排队后重新读值，使用官方 setter，等待新时间戳目标状态确认。一次一个命令，超时不重发，断线不重放。UI 不以“发送成功”冒充“车辆已执行”。完整函数、属性及编码见[官方车辆接口](OFFICIAL_CAR_API.md)。本轮自动验证不发送空调/座椅操作。
