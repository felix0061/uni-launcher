2026-10-27。包名 `xyz.i4o.uni.launcher`，版本 `0.6.16+27`。本轮仅本地与 Android 9 模拟器验证，没有连接或安装到车机。

## 桌面设置入口

在顶栏状态信息右侧加入无边框小齿轮：40 设计单位的点击区域、22 设计单位线性图标，复用现有 `IconAction`、主题色及按下反馈，不新增一行或底栏按钮。进入桌面设置后隐藏，编辑卡片时禁用。原有首页长按入口仍可用。

点击走同一 `LauncherController.openSettings`，不额外启动 Activity、Flutter engine、定时器或服务。

## 百度与腾讯地图

已读取 `amap/` 新增的两个 APK，分别核对内部交通灯模型、发送广播的方法、通知调用链和导出服务。

- 百度车机 22.0.1：内部有多方向模型和 `TRAFFIC_LIGHT_UPDATE`，追踪到进程内监听器；未建立到对外广播的调用链。另一个 OpenAPI 广播有功能开关、鉴权和接收权限要求，不能据此声称交通灯可读。
- 腾讯车机 9.11.0.159：多方向信息走 SDK Binder 回调；标准路线广播中确认的红绿灯字段是剩余灯数量。发现导出的 `NaviSdkService` 可作为后续 IPC 验证候选，尚未验证订阅握手、枚举与真实回调。
- 没有增加猜测的广播接收器；现有高德官方单项、yh 多项适配不变。完整结论与具体方法见 [多方向红绿灯接入范围](TRAFFIC_LIGHT_PROVIDERS.md)，输入哈希和证据索引见 [JSON](../analysis/navigation-provider-evidence.json)。

新增只读提取工具 `tools/analyze_navigation_signals.py`；整包字节码保留在 Git 忽略的 `analysis/raw/`，不把 APK 或第三方反编译源码加入源码仓库。
