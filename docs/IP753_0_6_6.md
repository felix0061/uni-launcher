# IP753 0.6.6 换屏优化与系统设置入口

日期：2026-10-26。包名 `xyz.i4o.uni.launcher`，版本 `0.6.6+17`。本轮完成本地构建、Android 9 模拟器验证及车机只读接口检查，未覆盖安装车机，未修改音量或音频焦点策略。

## 换屏

- 卡片使用 `NativeSliceBuilder` 只监听各自依赖的数据。隐藏页暂停数据驱动的重建，显示时直接读取最新状态，不丢数据。天气卡片在 60 次无关车辆快照更新期间只保持首次构建。
- 已布局的隐藏页保留元素、原生地图与上次布局，父约束变化延后到再次显示处理。对照测试中，两张隐藏页经历 12 次约束变化的布局次数从 24 次降到 0；动画帧没有额外页面布局，只有目标页绘制。
- 地图恢复由动画结束后的帧回调衔接，删除原先成功路径固定的 180ms、80ms 和 150ms 等待。仍保留生命周期代次校验、任务归位检查、失败重试及 PixelCopy 内容验证。410ms 是删除的固定等待总和，不是实车提速测量结果。
- 合并同一帧的地图可见性请求，忽略相同原生状态通知，避免重复平台通信和卡片重建。快速反向换屏时，原生 Surface 仍等动画结束后才显示；等待期间保留纹理预览。

Android 9 Hybrid Composition 的线程与合成成本参考 [Flutter 官方说明](https://docs.flutter.dev/platform-integration/android/platform-views)。本次没有切换到未经该车验证的地图渲染方案。实车换屏流畅度、地图返回时黑闪及生命周期恢复仍待停车复测，不以控件测试代替实车 FPS。

## 系统设置

入口：长按底栏首页 → 桌面设置 → 系统设置。

- 检索 Android `Settings.ACTION_*`、已安装设置应用的声明活动与 Manifest 的 Intent 入口，按来源分组。名称从应用本地化 label、dashboard 标题元数据和对应字符串资源读取；原车特殊入口使用动态资源名查找，不固定资源 ID。缺失页面名时保留应用提供的名称，不将技术 action 拼到显示名称中。
- 检查导出、启用、组件状态和调用方权限；点击前再次校验，只能启动本轮检索到的明确组件。未知 ID 不会打开任意活动。应用变更或用户点“重新检索”时刷新，日常快照使用缓存。
- 设置列表逐行延迟构建，原车设置优先展示，车辆或音乐更新不重建整份列表。完整目录仅在启动/主动刷新时传给 Flutter，不随每次车辆快照重复编码、传输；常规事件保留已有目录缓存。原车同一个 Activity 可以按不同 action 进入不同页，因此不按组件粗暴去重；只有相同组件和 action 去重。
- 最终模拟器版本实际 Launcher UID 检索 220 个入口。较早车机版本的 shell 只读探针检索 319 个入口，之后进一步排除了电话/联系人应用中与设置无关的活动。车机随后 ADB 离线，最终目录范围尚未在车机重跑。不同设备、权限和配置会影响结果，检索数量不代表所有页面均已打开验证。部分导出页可能还需要调用参数或原车内部状态，点击后能否显示内容仍需逐项验证。

## 导航播报与音乐

用户确认目标：导航播报时音乐继续播放，音量保持不变，既不暂停也不压低。

**该项尚未实现。** 已新增适配能力检查与界面状态，但这台 IP753 实际创建的对象是 `com.ecarx.xui.adaptapi.audio.audiofx.Audioimpl` 和 `AudioStateimpl`。核对本机 `/system/framework/ecarx.adapterapi.jar` 可见 `setNaviVoiceMixMode` 是空实现，读取固定返回 2。虽然定义了 `AUTO=1`、`DIRECTLY=2`，不能将固定读数当成可控或已启用的不降音模式。

适配器识别空实现后返回 unavailable，不展示可以生效的选择项，也不写猜测的系统属性。无效枚举在访问接口前拒绝；如未来出现真实实现，设置后必须回读确认。类不在应用 ClassLoader 时，只允许从只读系统 framework jar 加载。

本轮车机只读 `dumpsys audio` 显示选定的高德应用请求 `GAIN_TRANSIENT_MAY_DUCK`；播放器/系统的焦点策略仍会影响实际音量。可参考 [Android 音频焦点说明](https://developer.android.com/media/optimize/audio-focus)。后续需要核对当前导航版本的音频设置/受支持接口，并在停车状态确认导航能正常播报、音乐不暂停、实际听感不降音。当前没有以反复强制调整音量或抢占焦点的方式冒充完成。
