# 0.4.0 接入补齐与官方能力对照

本轮目标是准备可上车验证的实现。未连接车辆；模拟器测试源不是高德、网易云、QQ 或 ECARX 服务。本地 APK 静态证据与实际测试分别记录，不把候选接口等同于本车已通过。

## 导航卡片

- Flutter 卡片改为原生 PlatformView + Android 9 `ActivityView`，启动实际安装的导航 Activity；采用与嘟嘟 `Pip28View` 同类的完整应用嵌入路径，不把示意地图当作实况地图。
- 设置可选择已安装导航，默认识别高德车机版、精简版、32 位版及手机版，提供卡片嵌入开关和全屏入口。未安装、未授权、非 Android 9、容器失败分别显示原因。
- 在挂载 SurfaceView 前检查系统输入权限，防止 Android 异步 Surface 回调因缺权限导致宿主崩溃；声明权限不代表已获授权。本地开发签名不会自动获得系统签名权限。
- 容器准备后定向启动，尺寸变化同步位置；移除卡片/销毁时释放 VirtualDisplay；后台隐藏、前台恢复；编辑和设置缩略预览不启动额外地图。地图内部界面由高德绘制，不强制替换其配色。
- 当前普通权限模拟器验证的是缺权限降级、选择保存、全屏动作及生命周期编译。**未验证真高德嵌入成功**。上车需要确认实际签名/权限、允许嵌入与可缩放标志、Surface 合成、触摸坐标、缩放、休眠恢复、倒车接管和地图音频。

依据：本地 D07、`analysis/raw/dudu/bytecode.txt` 的 `Pip28View`；[AOSP Android 9 ActivityView](https://android.googlesource.com/platform/frameworks/base/+/android-9.0.0_r3/core/java/android/app/ActivityView.java) 中明确限定输入权限、目标 Activity 的可缩放和嵌入条件。[Flutter Platform Views](https://docs.flutter.dev/platform-integration/android/platform-views) 用于 Flutter/原生合成；Android 9 上的合成成本仍须实测，不作性能承诺。

## 播放器

设置可关联系统中已安装的原车媒体、网易云、QQ 等播放器，以包身份保存，显示应用名称。同一应用多个会话优先选择播放中的会话；明确选择后只读取/控制该应用，无会话时保持不可用，不能悄悄转而控制别的播放器。自动模式才会选择当前播放来源。

读取歌曲、作者、专辑、封面、歌词、播放位置/时长/速度，订阅 metadata、播放、extras 和会话销毁。按钮按当前会话 actions 启用，使用相同会话的 TransportControls；提供打开关联播放器入口。封面缩小缓存，车辆刷新不重复编码。通知授权入口沿用系统能力，不读取通知正文或请求账号密码。

网易云 `android.media.metadata.LYRIC` 的候选字段已来自嘟嘟证据；QQ Android/车机具体版本需验证是否暴露 MediaSession。嘟嘟 QQ 车机专用广播和 URI 控制已定位，但其发令含义、当前曲目关联和本车安装版本尚未核对，**本轮不把未确认协议当通用替代控制**。无会话版本可能需要后续专用适配。

两个独立的模拟器媒体源用于验证选择隔离、自动选择与状态变更、封面、歌词、播放/暂停、切歌、无会话回退和原生偏好保存；不代表对应商业播放器已实测。订阅所有活动会话的状态变化，避免自动模式只观察当前会话而漏掉另一个播放器；界面来源名随关联应用显示。

## 车辆数据

主路径保留官方 `Car.create → getICarFunction → getFunctionValue` 的配置探测，补充 PM2.5 支持状态。兼容读取按嘟嘟已确认的领克分支：`ecarxcar_service → IECarXCar → ECarXCar → car_publicattribute/car_signal`。不枚举或写入其他车型的数字 property ID。

| 字段 | 已实现候选 getter | 展示/验证策略 |
| --- | --- | --- |
| 主/副驾温度 | `getPA_CL_LeftTemp/RightTemp` | 按样本 raw/2；无效编码不显示；本车量程待核对 |
| 风量 | `getPA_CL_FanLevel` | 保留档位值，不推导风速 |
| AUTO、A/C、开关、循环 | `getPA_CL_Auto/AC/ClimateOn/Recirc` | 仅 0/1 映射，其他值未知 |
| 同步模式 | `getPA_CL_Sync` | 样本控制在 0/1/2 间循环，保留原始值，未核对语义前不按开关展示 |
| 主驾加热、通风，副驾加热 | `getPA_SHC_LeSts/SVC_Sts/SHC_RiSts` | 样本按 0–3 使用；每项独立有效性和只读 capability |
| 四轮胎压 | `getPA_dTPMS_TirePressureFrntLe/FrntRi/ReLe/ReRi` | 不猜 bar/kPa，保留原始值，并标注单位待核对 |
| 亮暗相关信号 | `getTwliBriSts` | 仅诊断原始值，不用未确认枚举改变自动主题 |

每个字段含原始值、显示值、getter、来源、单位、有效性、时间戳、`verified:false`。后台单线程最多每秒读取一轮；断连或超过 5 秒不继续显示旧值；单字段失败不影响其他字段。读取任务不会随重连无限增加线程，恢复时不重放任何车控。车辆详情支持复制读数供逐项比对。

**真实车控仍禁用。** 读取返回不证明命令、权限、单位和回读契约已验证。座椅、温度等界面可显示候选读数，但不调用 `CB_*`。SOC、油量、纯电/总续航、里程没有从本地领克分支确认可靠映射，保留原车应用入口，不套用其他车型接口。

## 天气图标

`WeatherKind` 与 `WeatherIcon/WeatherPainter` 是公共组件，当前天气和后续预报共用。覆盖晴、晴间多云、多云、阴、阵雨、雷雨、冰雹、小/中/大雨、三级暴雨、冻雨、雨夹雪、阵雪、小/中/大雪/暴雪、轻雾/雾/浓雾/强浓雾、四级霾、浮尘/扬沙/沙尘暴/强沙尘暴、大风/烈风/热带风暴、热、冷及未知。每种状态均有绘制实现；晴、间云、阵雨等需要天体时按昼夜绘制日/月，其余保持天气现象符号。

中文名称、常见同义词和变化天气已映射。不同供应商数字码含义不同，未声明来源的数字不强行映射；新状态回退未知符号。真实数据未同步时不会继续画晴天或保留演示温度。原生天气 Provider 尚未接通这一点没有改变。

## 上车准备

`tools/collect_car_readiness.py` 只读采集设备/窗口/已安装应用/权限/部件/服务/媒体状态，不安装、启动或控制车辆。输出目录不入 Git。真正读数可从车辆详情复制；按 [实车验收](CAR_ACCEPTANCE.md) 先逐项只读比较，再讨论正常可逆的控制测试。
