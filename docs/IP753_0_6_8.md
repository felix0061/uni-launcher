# IP753 0.6.8 实时地图纹理

2026-10-26，包名 `xyz.i4o.uni.launcher`，版本 `0.6.8+19`。

## 实现

地图改用 `LiveNavigationHost`：Android 9 VirtualDisplay 直接向 Flutter 管理的 SurfaceTexture 输出，高德实时画面由 Flutter `Texture` 合成。删除旧 ActivityView / PlatformView 容器、PixelCopy、JPEG 占位和预览 Canvas 队列。地图在换屏动画中也使用实时纹理，没有生成静态地图替代图；隐藏页保留同一个显示容器和生产 Surface，Flutter 不绘制隐藏页。

帧消费回调确认首次实时画面到达；之后仅递增诊断计数，不逐帧传输图片、平台事件或重建控件。按卡片实际像素创建显示尺寸，普通动画不调整地图分辨率；卡片实际尺寸变化才 resize。尺寸限制为 1920×1080。删除卡片或宿主销毁时释放显示容器、Surface、纹理和输入转发器。

触控按卡片归一化坐标转换到虚拟显示，支持最多十个指针及按下、移动、抬起、取消。地图手势主动接管手势竞争，拖动或双指缩放不同时翻桌面；编辑状态交回卡片拖放。进入设置、隐藏页面或弹窗时停止向地图转发输入，保留其纹理生命周期。高德的正常原生窗口不会独立浮到 Flutter 设置页之上。

普通换屏和弹窗关闭复用已有地图任务，只在必要时把它归位到虚拟显示，不重复发送 singleTask 启动 Intent。全屏入口仍将同一个任务移到物理主屏；返回桌面时移回。地图无现有任务时解析其声明的直接入口启动。Android 9 模拟器未声明 `activities_on_secondary_displays`，首次启动时系统可能忽略 launchDisplayId；已保留任务归位检查。实车声明该特性，但仍以实际行为验收。

实时地图不等于实时截图毛玻璃：没有新增跨应用连续采样或实时跨窗口模糊。0.6.7 的引擎共享、缓存上限、临时面板释放继续保留。

## 验证

- Flutter 104 项测试通过，analyze 无问题；arm64 / x86_64 release 构建通过。覆盖实时纹理生命周期、快速换屏、布局尺寸不随动画 resize、包切换和异步创建取消、双指消息、编辑手势、设置及弹窗输入隔离。
- Android 9 / 1920×1080 模拟器使用平台签名 Launcher 与独立合成地图测试源，真实经过 VirtualDisplay、帧消费和 IInputForwarder。实时帧持续推进，实际按下/拖动与双指事件到达测试 Activity；四轮换屏保持纹理 ID、显示 ID、尺寸、启动次数，resize 为零。设置及音乐弹窗输入不穿透，窗口截图已检查。全屏后返回原显示容器，活动显示容器为一个，强制停止宿主后系统异步释放到零。
- 可复现测试：`tools/build_live_map_fixture.py` 与 `tools/verify_live_navigation.py`。两者限制模拟器；TouchProbe 自身也检查 `ro.kernel.qemu`。合成应用的包名用于命中导航识别，不是高德 APK，不得安装车机。结果与截图见 `app/verification/live-navigation/`。模拟器结果不能代替高德 / 原车兼容性结论。
- 用户确认停车及 P 挡后，实车覆盖安装 0.6.8；按先前授权重启高德清理旧版本残留层。初始接入 `renderMode=realtime`，1229×782，显示 ID 11，首次检查已消费 347 帧，resize 为零，地图正常显示，截图未见初始重复图层。网易云仍在播放。
- 随后准备进行四轮换屏、拖动、媒体弹窗、设置和全屏返回回归时，ADB 已离线，脚本在首次读取状态就停止，没有执行这些界面操作。因此这些 **实车回归仍待续**，不把模拟器结果或初始截图当作全部通过。原始现场文件位于忽略入库的 `car-reports/20261026-068-live/`。
