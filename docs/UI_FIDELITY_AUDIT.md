## 新增座椅控制

空调入口内增加三行：主驾座椅加热、主驾通风、副驾加热；每行显式选择关闭、1、2、3档。不新增底栏入口，不添加副驾通风。设计与 Flutter 共用原创座椅符号、四等分选档和派生圆角。

0–3 档与主驾加热/通风互斥仅为演示规则。本地 D02/D03 证据确认候选 `CB_SHC_LeLvl/RiLvl`、`CB_SVC_Lvl`，未证明本车可直接使用、档位枚举或互斥契约。真实适配器不写座椅；三个控件分别检查自己的 `seatCapabilities`，普通空调权限不能授予座椅权限，模拟值不能作为实时回读。

## 歌词与翻屏补充

音乐卡片和底栏增加同步单行歌词，详情增加三行滚动歌词；默认音乐卡封面由 210 调整为 180 设计像素，为歌词留出空间。进度改由实际会话驱动。设置新增「切换动效」标签，三项圆角矩形选项沿用公共主题和按钮组件；默认无动画，底栏固定。设计源与 PNG 同步更新。通道依据和实车边界见[歌词与动效说明](MEDIA_LYRICS_AND_MOTION.md)。
