# IP753 0.6.9 红绿灯卡片

包名 `xyz.i4o.uni.launcher`，版本 `0.6.9+20`。沿用 Flutter 和现有车辆、媒体、实时地图模块；本轮没有操作车机。

## 使用与界面

长按桌面进入编辑 → 添加卡片 → 桌面扩展 → 红绿灯。保留当前两屏默认布局，不自动插入新卡。可自由移动、缩放、重命名、删除，保存和重启后保留。预设 4×2、4×3、8×3、8×6。

标题打开当前关联的地图，显示用户按包名保存的应用名称。关联设置与导航卡片共用；新增自动识别 `com.autonavi.amapautp.yh`。单方向使用紧凑布局，多方向并排，较窄卡片显示两个方向，较宽显示三个，更多方向在页脚提示并引导打开地图。深浅色、智能配色、圆角和表面效果使用已有主题组件，没有增加独立高频模糊或地图截图。

箭头、秒数、单位和灯态文字独立布局，使用等宽数字。空状态为“等待路口信号”；超时为“信号暂未更新”，移除旧数字。倒计时到零显示 `—`，不自行变灯。

## 接入与已知边界

- 官方标准广播 `AUTONAVI_STANDARD_BROADCAST_SEND` / `KEY_TYPE=60073`：接收方向、灯态和 `redLightCountDownSeconds`；保留可选等待轮次和 `greenLightLastSecond` 原始值用于诊断，不把后者直接当绿灯倒计时。
- 修改版 `NAVITOOL_CRUISE_TRAFFIC_LIGHTS` / `data` JSON：同批替换整个方向数组。空数组立即清空，异常数组整体拒绝；最多 16 个方向、16 KiB JSON。有效多方向数据优先于同时抵达的单方向标准广播，不跨批次拼接方向。
- 接收器与应用级 `LauncherRuntime` 共用，各 Flutter 引擎不重复注册。最后一个订阅者离开时注销并取消超时任务。切换关联导航或包变更导致选择变化时清空旧批次；关联其他厂商地图时忽略高德广播。
- 原始方向与灯态枚举尚未核实，当前 live 路径明确输出 `enumVerified=false`。**实车第一版使用中性色和通用信号图标，展示收到的倒计时及“灯态待确认”，不会把未确认数值显示成左转或绿灯。** 原始值可在 `dumpsys activity xyz.i4o.uni.launcher/.MainActivity --uni-state` 的 `trafficLights` 中读取。需将这些数值与真实高德画面比对后，再补充每种协议的枚举映射。
- 广播本身没有可靠的发送者标识；导航关联筛选协议，不代表验证了发送方身份。两种高德同时运行时标准广播来源不能精确区分，不把卡片用于车辆控制。
- 暂定新鲜度为 5 秒，按本机单调时钟计算。停止播发后最多 5 秒清空；本轮未猜测导航退出的未知状态码，导航退出信号目前依赖这个超时。真实更新间隔、断网和路口切换需要上车调整。修改版发送端 `ts` 不用于推断信号变化。
- 每张可见 live 卡片只按秒刷新自身，不发布全桌面秒级事件。隐藏页、设置预览、后台和编辑期间取消计时器；再次显示时按实际已过时间判断是否失效。父级主题或名称重建不会重启旧倒计时。
- 演示模式仅显示明确的示例灯组，保持固定示例数字，不与实车数据混合。

## 验证

- Flutter 全套组件 / 状态测试通过；新增测试覆盖输入、未知枚举、过期、倒计时零值、隐藏页、父级重建、最小尺寸、深浅色 / 直角 / 表面设置、标题启动、编辑禁用、卡片库与布局重载。
- Java `AmapTrafficLightProtocolTest` 三项测试通过：数字类型与范围、原始值保留、无关广播过滤、多方向原子性、空数组和大小上限。
- Android 9 / 1920×1080：真实 `LauncherRuntime` 接收合成广播，10 项检查通过。包含标准信号、多方向、并发优先级、无关广播、异常输入、5 秒超时、空数组和其他导航应用关联过滤。使用测试专用模拟器并保存 / 恢复偏好，没有安装真实官方或修改版高德 APK。
- Android 9 上使用生产 Flutter 卡片导出四张界面：深色、浅色、0 圆角和表面开关，包含单方向、多方向、未知枚举、等待和超时。截图内明确标注示例数据。见 [深色截图](../app/verification/traffic-lights/traffic-lights-dark-28-false.png)、[浅色截图](../app/verification/traffic-lights/traffic-lights-light-28-false.png)。
- 原生链路报告：[native-report.json](../app/verification/traffic-lights/native-report.json)；视觉集成报告：[gallery-report.json](../app/verification/traffic-lights/gallery-report.json)。模拟器结果不代表真实路口覆盖率、枚举确认或实车性能。

签名产物和最终检查摘要记录在 `app/verification/traffic-lights/release-report.json`。

## 复现

```sh
cd app
python3 tools/flutter_task.py analyze --no-pub
python3 tools/flutter_task.py test --no-pub
python3 tools/flutter_task.py drive --driver=test_driver/traffic_light_driver.dart --target=integration_test/traffic_light_gallery_test.dart --debug -d emulator-5580
python3 tools/flutter_task.py build apk --debug --target-platform android-x64
adb -s emulator-5580 install -r build/app/outputs/flutter-apk/app-debug.apk
python3 ../tools/verify_traffic_lights.py --serial emulator-5580
```

Java 协议测试使用 `app/android/gradlew :app:testDebugUnitTest`（在 `app/android` 目录运行，配置本机 Java 17）。真车下一步只需安装同证书升级包并添加卡片，在高德实际显示信号时读取诊断与截图；核对枚举、更新周期和导航退出后清空，不需要重新替换桌面或重置布局。
