# 新增主题提案：深蓝玻璃 / Blue Glass

本轮为视觉方案；没有修改 Flutter 应用、车机通信或发布 APK。以当前 UNI 卡片、播放器和全局底栏为内容基础，新增一套可选择的材质样式。

## 两张本地参考的取舍

- `theme-styles/style_01.png`：借鉴深蓝底色、信息分组、细亮边框、数据与图表的清晰层级。光晕收敛到面板上沿和操作反馈，不采用整屏霓虹、紫蓝泛光或装饰仪表。
- `theme-styles/style_11.jpeg`：借鉴玻璃面板的冷色反光、冰蓝主操作、轮廓明确的图标按钮。将手机小卡片适配为车机大面积地图、可读歌词与连续底栏。

设计判断：现有风格的大范围泛青渐变、较大的统一圆角、柔和外阴影叠加，容易形成模板化观感。新方案用深浅明确的表面、细轮廓和稳定字号建立层级，蓝色集中用于当前状态与可操作入口。参考图本身的玻璃特征保留，装饰强度降低。

| 主文字 | `#F2F6FC` | `#172B42` |
| 次要文字 | `#A2B3C7` | `#52687F` |
| 默认强调色 | `#83B6FF` | `#245BC1` |
| 主操作按钮 | `#3276EE` | `#2867DF` |
| 边框 | `#31475E` | `#CAD6E4` |
| 全局底栏 | `#0C1929` | `#F5F8FC` |

卡片示例圆角 22 px；主要按钮 12–14 px，普通图标按钮 12 px。继续支持用户 0–40 px 的圆角选择，0 时保持直角，不能被新样式硬编码覆盖。尺寸均为 1920×1080 画板像素，Flutter 实现继续走现有 Design 缩放。

玻璃质感以静态面板色阶、1 px 边框、上沿细反光与小范围阴影表达。稿中不使用 CSS backdrop-filter、实时模糊、漂浮光斑或循环光效；后续 Flutter 应采用相同静态绘制思路，避免重新引入 820A 的逐帧滤镜开销。用户壁纸仍可使用，卡片保留足够实色遮蔽以保证可读性。

灯色、告警、空气质量保留语义色，不全部染成主题蓝。音乐 APP 图标也保留应用识别色。

## 关键组件

- 首页继续 8×6 导航、4×4 音乐、4×2 天气。音乐标题为 APP 图标 + 名称 + 正在播放；左侧专辑/歌曲/歌手/专辑名，右侧歌词。当前句使用正文亮度与细竖线，弱化整块发光。
- 车辆卡片的数值是第一层级，单位与来源/状态退到次要层级。车辆线稿不另加光圈；能量流仅在真实有流向时运动，静止或过期时降为静态。
- 底栏 96 px 高、全宽直角贴底。顺序仍为返回、首页、全部应用、最近任务、360、空调、媒体控制/歌曲/歌词、车辆信息；无额外左侧栏、无常驻设置图标。全局底栏图标不添加文字。
- 底栏首页仅在对应页面选中；设置页关闭首页高亮。选中态为蓝灰底与细边框，按下态只变局部底色，避免整条底栏发光或跳动。
- 弹窗沿用同一面板、边框、圆角和按钮样式；账号、天气、音乐、空调保持现有入口与功能。选中/禁用/告警三种状态必须独立，不靠透明度替代文字对比度。

## 设置中的关系

新增 `主题样式：经典 / 深蓝玻璃`。这控制材质和控件外观；与已有的 `主题风格：智能调色 / 跟随系统 / 浅色 / 深色` 分开。

主题色仍支持预设与自定义。稿中以冰蓝为新样式的推荐配色，其他预设显示雾青、蓝紫、暖砂、灰玫；实现时可映射现有五组颜色，保持用户自定义色和已保存圆角。新样式不能清除布局、应用重命名、壁纸或播放器/导航关联。

设置稿里的“玻璃质感”拟用于控制静态边缘反光和面板层次；需要明确与旧版毛玻璃开关的兼容映射，不能开启后偷偷切回实时背景模糊。预览区域保持 16:9。

## 后续实现拆分

1. `Appearance` 增加独立主题样式标识，旧设计缺省映射经典；完整保留现有用户配置。
2. `SurfaceStyle` / 主题 token 提供背景、卡片、边框、文字、控件和静态反光参数；复用 `GlassSurface`、`IconAction`、`LauncherSheet` 等公共组件。
3. 底栏、卡片、设置、最近任务与弹窗统一消费样式；不为每张卡复制一套 UI 或改变车辆接口。
4. 检查自定义圆角、深浅模式、壁纸、主题色、禁用态、数据显示不完整和多屏运动，之后在 820A 对比 GPU 帧耗时。

## 本轮检查

运行 `node tools/render_blue_glass.mjs` 可重建四张 PNG；使用隔离的本地 Chromium profile，不访问个人浏览器。检查 1920×1080、面板内容包含、底栏贴底、卡片不被底栏遮挡、所有图片解码、无实时滤镜、设置预览 16:9，以及车辆横向比例和胎压不覆盖线稿。结果见 [review-report.json](../design/blue-glass/review-report.json)。此为设计排版检查，不能替代 Flutter / 实车验证。
