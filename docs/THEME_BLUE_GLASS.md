# 新增主题提案：深蓝玻璃 / Blue Glass

本轮为视觉方案；没有修改 Flutter 应用、车机通信或发布 APK。以当前 UNI 卡片、播放器和全局底栏为内容基础，新增一套可选择的材质样式。

## 两张本地参考的取舍

- `theme-styles/style_01.png`：借鉴深蓝底色、信息分组、细亮边框、数据与图表的清晰层级。光晕收敛到面板上沿和操作反馈，不采用整屏霓虹、紫蓝泛光或装饰仪表。
- `theme-styles/style_11.jpeg`：借鉴玻璃面板的冷色反光、冰蓝主操作、轮廓明确的图标按钮。将手机小卡片适配为车机大面积地图、可读歌词与连续底栏。

设计判断：现有风格的大范围泛青渐变、较大的统一圆角、柔和外阴影叠加，容易形成模板化观感。新方案用深浅明确的表面、细轮廓和稳定字号建立层级，蓝色集中用于当前状态与可操作入口。参考图本身的玻璃特征保留，装饰强度降低。

卡片示例圆角 22 px；主要按钮 12–14 px，普通图标按钮 12 px。继续支持用户 0–40 px 的圆角选择，0 时保持直角，不能被新样式硬编码覆盖。尺寸均为 1920×1080 画板像素，Flutter 实现继续走现有 Design 缩放。

玻璃质感以静态面板色阶、1 px 边框、上沿细反光与小范围阴影表达。稿中不使用 CSS backdrop-filter、实时模糊、漂浮光斑或循环光效；后续 Flutter 应采用相同静态绘制思路，避免重新引入 820A 的逐帧滤镜开销。用户壁纸仍可使用，卡片保留足够实色遮蔽以保证可读性。

灯色、告警、空气质量保留语义色，不全部染成主题蓝。音乐 APP 图标也保留应用识别色。

## 关键组件

- 首页继续 8×6 导航、4×4 音乐、4×2 天气。音乐标题为 APP 图标 + 名称 + 正在播放；左侧专辑/歌曲/歌手/专辑名，右侧歌词。当前句使用正文亮度与细竖线，弱化整块发光。
- 车辆卡片的数值是第一层级，单位与来源/状态退到次要层级。车辆线稿不另加光圈；能量流仅在真实有流向时运动，静止或过期时降为静态。
- 底栏 96 px 高、全宽直角贴底。顺序仍为返回、首页、全部应用、最近任务、360、空调、媒体控制/歌曲/歌词、车辆信息；无额外左侧栏、无常驻设置图标。全局底栏图标不添加文字。
- 底栏首页仅在对应页面选中；设置页关闭首页高亮。选中态为蓝灰底与细边框，按下态只变局部底色，避免整条底栏发光或跳动。
- 弹窗沿用同一面板、边框、圆角和按钮样式；账号、天气、音乐、空调保持现有入口与功能。选中/禁用/告警三种状态必须独立，不靠透明度替代文字对比度。

## 设置中的关系

新增 `主题样式：经典 / 深蓝玻璃`。这控制材质和控件外观；与已有的 `主题风格：智能调色 / 跟随系统 / 浅色 / 深色` 分开。

主题色仍支持预设与自定义。稿中以冰蓝为新样式的推荐配色，其他预设显示雾青、蓝紫、暖砂、灰玫；实现时可映射现有五组颜色，保持用户自定义色和已保存圆角。新样式不能清除布局、应用重命名、壁纸或播放器/导航关联。

设置稿里的“玻璃质感”拟用于控制静态边缘反光和面板层次；需要明确与旧版毛玻璃开关的兼容映射，不能开启后偷偷切回实时背景模糊。预览区域保持 16:9。

## 后续实现拆分

1. `Appearance` 增加独立主题样式标识，旧设计缺省映射经典；完整保留现有用户配置。
2. `SurfaceStyle` / 主题 token 提供背景、卡片、边框、文字、控件和静态反光参数；复用 `GlassSurface`、`IconAction`、`LauncherSheet` 等公共组件。
3. 底栏、卡片、设置、最近任务与弹窗统一消费样式；不为每张卡复制一套 UI 或改变车辆接口。
4. 检查自定义圆角、深浅模式、壁纸、主题色、禁用态、数据显示不完整和多屏运动，之后在 820A 对比 GPU 帧耗时。

### 边框与玻璃的分工

主体面板采用弱 1 px 连续线，四角各两段 18 px × 1.5 px 短线。暗色普通边线 `#283B4F`、角线 `#829AB2`；浅色普通边线 `#C3D1DF`、角线 `#738DA8`。角线是中性的结构提示，主题蓝用于选中状态、进度与主操作；不让所有边框持续发光。

玻璃面板保留约 94% 的基底色遮蔽，并叠加很低强度的固定反光色阶；轻微上沿反光和小范围阴影帮助区分面板与背景。透色不是实时模糊：没有背景采样、流光、扫描线或动画滤镜。若配合复杂壁纸，仍应优先保证文字底色稳定。

四角推荐配接近直角的外形，本版稿用 0 px；小按钮用 8 px，信息标签约 4 px，形成外部利落、内部便于触控的层次。它是新样式的推荐默认形状，不废弃已有 0–40 px 圆角选择。实现阶段，用户增大圆角后角线要跟随边缘成为短弧，不能在圆角内绘制悬空的直角；不强制重置已有用户配置。

主体卡片与大的设置/详情面板使用四角框线。按钮、每个数据格、专辑封面、状态标签不再重复四角装饰。全局底栏保持全宽 96 px、外形直角、贴底，只用一条顶部分界线。编辑选中时可把该卡角线改为主题色，普通状态维持灰蓝色；错误/告警仍通过内容语义色表达。

### 实现建议与设计验证

建议把它作为“深蓝玻璃”的推荐外框，而非再增加一个独立主题。由公共 Surface/Panel 的 FramePainter 统一绘制连续外线与八段角线，再叠加静态玻璃底；标题、数据、地图和播放器组件不因此复制。实车成本需实现后再测，不以设计稿断言性能无损。

网页稿使用独立 `technical-frame.css` 和 `?frame=technical`，不影响原版评审稿，也未改动 Flutter 应用。复现：

```sh
node tools/render_blue_glass.mjs --technical
```

### 状态层级

| 类型 | 框线与底色 | 说明 |
| --- | --- | --- |
| 普通图标 | 无常驻色块，正文图标 | 由间距建立秩序 |
| 持续选中 | 主题色短角线、弱连续线、约 11% 主题色混入的底色 | 如首页选中、当前明暗模式、主题样式 |
| 按下 | 局部底色约 20% 主题色混入 | 不缩放、不改布局和触控框；松手恢复 |
| 禁用 | 降低图标对比，无选中角线 | 不与选中状态混淆 |
| 播放/暂停主操作 | 中性灰蓝短角线、白色/深色正文图标、实色弱底 | 是即时命令，不能伪装成导航选中；按下后再突出主题色 |

主体卡片角线仍为 18 px；设置大选项为 10–12 px，图标按钮 7–8 px，角线宽 1–1.5 px。设计中的选中框与按钮自身的可见边界完全一致。图标控件示例保持 58×58 px，设置预览及底栏都不因选中改变外框尺寸。实现应沿用实际触控区域，不能按小角线范围缩小点击区。

标签页继续以短下划线标记当前位置；标准颜色选择器保留圆形色点与选色环。小开关用小矩形轨道、主题色短角线和清楚的滑块位置。用户配置非零圆角时，所有框线仍应跟随对应控件轮廓；本稿基于 0 圆角推荐样式。

### 全局底栏的统一

1. **整体材质**：与主体卡片共用深蓝/雾白基底和低强度静态玻璃反光；全宽 96 px、0 外圆角、贴底，外框只保留顶部细分界，不再加整条装饰角线。
2. **导航区域**：返回、首页、全部应用、最近任务、360 使用同样的图标尺寸、间隔和状态。首页仅在桌面首页选中；在设置或外部应用中恢复普通态。车辆入口也为普通图标，打开相关面板后才可标记选中。
3. **空调区域**：双区温度、风量入口与电源组成一块低对比玻璃控制区，外围中性短角线。加减键保持简单，避免每个小按钮都套框；数值和图标垂直居中。
4. **音乐区域**：取消旧方案大面积实心蓝色播放键，使用中性框线主操作；上一首/下一首同一尺寸与笔画。封面改为接近直角的小矩形，歌曲/歌手保持固定层级；歌词居中，延续最多两行的既有要求。
5. **连续性**：外部应用与桌面使用相同的底栏方案与状态，不以不同材质表示应用切换。设计对照图中的第二条底栏展示外部应用场景：首页不高亮，空调、音乐照常可见。这里只展示外观，不冒充新增的系统层验证。

主题、卡片、底栏、设置的状态应在 Flutter 中统一由 `FramePainter`、`SurfaceStyle` 和控件状态 token 驱动，不为全局底栏另做一套颜色与按下动画。静态玻璃、角线和阴影都不加入循环动效或实时模糊。
